# Historical project records

These files preserve planning and requirement history. They include internal
course and milestone language that is intentionally kept out of TrailPack's
public introduction.

- [`plans/`](plans/) contains dated implementation plans and schedules.
- [`specs/`](specs/) contains the original supported-trail, scenario-review, and
  continuation requirement specifications.
- [Priority 1 roadmap snapshot](2026-09-09-improvement-roadmap-snapshot.md)
  preserves the detailed access-route and future-map brief before the roadmap
  was shortened.

Use the current [product roadmap](../../roadmap.md) for new work. When a current
decision conflicts with a historical plan, keep the old record intact and
document the new decision in the roadmap, domain context, or an ADR.
